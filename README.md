# HTML Toolbox · 常用 HTML 小工具库

这里收集日常设计、电商视觉和图片处理工作中常用的 HTML 小工具。每个工具尽量保持为**单个、可直接打开的 HTML 文件**，无需复杂构建。

## 工具目录

| 工具 | 功能 | 在线体验 | HTML 源文件 |
| --- | --- | --- | --- |
| **图片实时对比工具** · v1.1 | 原图与多参考图联动对比、水平/垂直滑动、归一化对齐、黑底差异、ΔE2000 热力图、临时智能缓存 | [在线体验 ↗](https://www.showyourcode.app/share/qglr1umvdox0cy) | [查看 HTML](./图片实时对比工具.html) |
| **移动端三模式图片预览** | 多图拖拽导入、按文件名排序、默认／天猫／京东三种详情页预览模式 | [在线体验 ↗](https://www.showyourcode.app/zh/share/9d248f9e-dd87-4ac8-b366-741d319b6338) | [查看 HTML](./移动端三模式图片预览.html) |

> **关于体验版：** 在线体验地址由工具发布页面提供，不属于此 GitHub 仓库的自动部署。GitHub 源文件可能更新得更快，二者版本不一定实时同步。

## 文件结构

```text
HTML-Toolbox/
├── README.md
├── 图片实时对比工具.html
└── 移动端三模式图片预览.html
```

**目录规则：**
- 工具 HTML 直接放在仓库根目录，文件名包含清晰的中文工具名称；不为单个工具增加目录。
- 根目录 README 是唯一的工具导航，新增工具时同步增加「在线体验 + HTML」两个入口。
- 一个工具尽量维护一个稳定文件名，功能升级通过 Git 提交历史追踪，不以每个版本新建文件。
- 优先保持纯前端、可本地打开。需要外部脚本、素材或网络的功能在说明中注明。

## 使用方式

1. **立即体验：** 点击上表的「在线体验」进入外部体验页。
2. **获取 HTML：** 点击「查看 HTML」，在 GitHub 文件页面使用 **Download raw file** 保存，再双击本地运行。
3. **继续添加：** 把新的单文件 HTML 发来，连同可用的体验地址；仓库按相同规范收录和维护。

## 使用提示

- 图片实时对比工具在浏览器本地处理导入图片，热力图缓存仅保留在当前页面会话；网页使用 Tailwind CSS 和 Lucide 的 CDN 资源，初次打开样式与图标需要联网。
- 移动端三模式图片预览在默认、天猫、京东模式间切换；京东模式支持可选的 `header-bg.png` 背景图，上传时可与详情图片一同选择。
