先认识工作台

新手#

把同一批人物照片，按景别、留白、避让区域和输出规格裁切；需要补背景时连接 ComfyUI 扩图，最后按命名规则下载。

工作台主要处理人物照片的构图与多规格输出。识别得到的骨骼和人体轮廓是裁切参考，不是对服装边缘、发型、姿势和审美的完整判断。坐姿、遮挡、多人、帽子及边缘细节要重点查看。

左侧裁切规则景别 · 必保 · 避让 · 留白中央查看与复核单图编辑 / 输出批量效果右侧批量输出管理组合 · 规格 · 命名 · 导出

先分清这四件事

识别
找人物、关节与轮廓。图片不变时，通常不必因为调整规则而重新识别。
裁切计算
按当前规则求裁切框。切比例、改留白和景别，主要是在重算这个框。
外扩
裁切框超出原图，就需要额外背景。几何外扩只是预留空间；纯色或 AI 决定怎样填充。
导出
根据规格生成真正的图片文件。只在画布里放大、拖动或隐藏参考图层，不会改输出像素。

推荐打开方式

  • 已有本地后台：使用蓝调工作台入口。
  • 独立浏览器工作台：优先使用固定 HTTP 地址，例如 http://127.0.0.1:8766/，便于模型和模板持续缓存。
  • 已将 HTML 部署到 ComfyUI 静态目录时，可打开 http://127.0.0.1:8188/hongs-crop-browser.html，它与 ComfyUI 同源。

HTML 可以改名或移动。ComfyUI 的 CORS 不绑定某个文件名，但页面网址改变后，缓存、来源许可和同源入口也可能变化。直接双击 HTML 的 file:// 方式受浏览器本地网络与存储策略影响；本指南不把它等同于 HTTP 方式已经验证的全部能力。

单 HTML 内包含界面、JavaScript 与 WASM 运行库，不包含模型权重。首次识别需要下载模型；已缓存并可正常读取时可复用。AI 扩图仍需要运行中的 ComfyUI。

第一次使用：导出一张图

新手#
  1. 打开工作台，先导入一张照片。

    点“导入照片”或把照片拖入中央区域。无识别和复核记录时会自动裁切识别。

  2. 等识别完成，选择预设和比例。

    例如“含头 · 膝上紧凑”与 3:4。先确认头发、手和衣服关键部位没有被裁掉。

  3. 检查输出尺寸。

    画布上方可直接改宽高，与左侧试算尺寸同步；当前比例会保持。回车或移出输入框确认。

  4. 需要时进入“人工复核”。

    拖动裁切框或调整必保范围，完成后点击“确认复核”。

  5. 下载当前图片。

    画布右上角下载图标 →“当前画幅 PNG”。如需补背景，先看纯色与 AI 设置。

第一次先做这个检查

打开下载的 PNG，确认像素尺寸、人物范围和留白。确认这一张符合要求，再设置多规格、批量识别和批量导出。

只看到虚拟骨架时，尚未在处理真实照片。虚拟骨架用于试验规则，不会作为照片导出。

导入、切换与识别

新手#

可一次选择多张图片，也可拖入多图。底部缩略图显示序号、选中状态及识别状态。点缩略图、上一张 / 下一张，或在非输入状态使用 ← / → 切换。

  • 无记录：导入或切换后自动识别。
  • 已有识别或复核：复用本页记录，不因普通规则调整重复跑模型。
  • 需要重跑：点“裁切识别”。它与“实拍识别”调用同一识别能力。
  • 移除：缩略图右上角 × 移除单张；垃圾桶清空本页全部图片及对应识别、复核数据，不删除磁盘原文件。

多人识别与单人快速

人数不确定或合影时使用多人识别。主体明确的单人图可用单人快速。切换模式或识别引擎后，已有结果不会自动全部重跑；希望使用新模式时，对对应图片重新点击裁切识别。

失败后怎样处理

先查看底部错误与右上角模型状态。模型未就绪时检查下载和缓存；本地 Holistic 报缺少依赖时检查项目运行环境。识别不到人物不代表图中没有人物，可切换引擎或人工标记必保范围。

切换图片会恢复默认显示。整片灰色画板支持滚轮缩放、空格或鼠标中键拖动，左侧工具、数字框和底部骨架控件保留各自操作。输入框或弹窗中按空格不会触发画布拖动。

比例与尺寸

支持 1:1、3:4、2:3、4:3、16:9、9:16。画布上方与左侧宽高双向同步；输入一边后另一边按比例调整，必要时对齐到比例整数单位。比如 9:16 中宽度 1080 对应高度 1920。

当前输出卡片处于联动时，顶部、左侧与该卡片同步；解除联动后，只修改独立试算。右侧其余规格不会一起改变。

画面上的框和颜色

实线框为成片边界，压暗区域不会出现在对应成片里。绿色参考范围用于说明实际保护区域；红、橙等区域代表避让强度。棋盘格表示透明或尚需填充的位置，不表示 AI 已经生成。

自由调整、横移与纵移

基础#

景别范围 / 必保底线标题右侧的胶囊控制整个画幅的调整方向。

  • 自由调整：按景别、必保和留白计算裁切。
  • 仅横移：保留原图全部上下边界，只调整左右裁切或外扩。
  • 仅纵移：保留原图全部左右边界，只调整上下裁切或外扩。

横移和纵移时，景别作为人物定位及避让参照，不会将完整画幅缩成局部身体区域。目标比例决定允许调整方向的画幅尺寸；另一方向保持原图边界。参照范围放不下时给出警示，不能保证保留全部参照。

新增“含头 · 到肩膀”预设，景别与最低必保下边界也可选择肩膀。

多个避让区域的顺序

横移和纵移时，从上到下处理避让区域。两个区域要求冲突时，上方优先，下方本次忽略，并显示冲突图标；用卡片左侧上下箭头调整顺序。自由模式仍按严格、适中、宽松比较。

切换比例的缓存

同一张图已计算的比例、尺寸及规则结果会复用。修改景别、避让、留白、识别数据或复核标记后重新计算。首次或修改参数后的计算仍需要时间；缓存不保存到磁盘，刷新页面后重新建立。比例往返切换使用稳定宽度基准，手动调整尺寸后更新基准。

模型下载、缓存与识别差异

进阶#

点顶部模型状态，打开“浏览器运行设置”。这里可选择首选下载来源、加载 / 重试、清除模型缓存、导入合法的 .task 文件，并查看下载记录。

v1.1.6 起，浏览器按每个人的独立分割蒙版提取与脸部相连的头发轮廓，用于头部必保与避让；多人蒙版不会直接合并成一个头部。轮廓缺失时仍使用估算并提示复核，不能保证识别所有帽子、遮挡和贴靠人物。

自动下载怎样工作

  1. 先检查浏览器缓存，读取后校验大小与 SHA-256。
  2. 没有可用缓存时尝试下载；自动来源顺序为国内 HF-Mirror、Google 官方、Hugging Face。
  3. 连接失败、无数据、HTTP 错误或校验失败时尝试其他来源。
  4. 保存时依次尝试 Cache Storage、IndexedDB；持久存储不可用时可暂存内存，并明确显示。

当前 Pose Landmarker Full 权重约 9.4 MB。选择其他来源仍要求同一份权重通过固定哈希校验，不是任意模型都能导入。模型状态“已缓存 / 就绪”与某张图是否识别成功是两件事。

识别模式特点使用注意
本地 Holistic项目 Python 环境运行，提供精细手部观测项目需有可用 MediaPipe Solutions，不能随意改为全局 Python 启动
浏览器 Pose LandmarkerCPU WASM；最多 6 人；姿态与分割轮廓手部为 4 点粗略观测，不是 21 点精细手部

两端选择相同浏览器引擎时共享模型、预处理与裁切核心；Holistic 与 Pose Landmarker 的识别输出不承诺相同。浏览器先将整张照片等比放入 1024 方形输入；本地多人流程先检测人物，再在人物局部运行 Holistic。多人靠近、搭肩、遮挡和小手掌的误差可能来自模型与输入策略，不能把四个姿态手点当作完整手掌边界。缓存位于当前浏览器 / 站点，更换 localhost、127.0.0.1、端口或浏览器后，可能需要重新下载。

景别范围与必保底线

进阶#

左侧默认折叠的“景别范围 / 必保底线”包含两层要求。理想景别是希望保留的范围；最低必保是退让时仍应保留的范围。

参数含义常见设置
上边界 / 起点从人物哪个部位开始保留头部、肩部、腰部稍上、胯部
下边界 / 底线至少保留到哪个部位膝上、膝盖、腿肚、脚底等
手部按每个人要求至少一只、双手，或不额外保护“尽量”可退让，“强制”缺可靠观测时需重点复核
额外外补相对于最低必保方案，偏好可额外使用的外补百分点15 代表 15 个百分点，不是像素
自动缩短景别理想范围难满足时尝试更短的景别不会把最低必保一起调短
缺失比例估算按可靠骨骼推测缺失参照推测位置需检查，不是补出真实身体
特写按原图扩画幅缺少可靠人体参照时保留原图并扩到目标比例结果会提醒复核

景别是保留范围要求，不是让某个身体点精确贴到成片边缘。比例、手部和留白可能让实际保留范围更多。先选接近需求的预设，再调少量参数，比从空白规则开始更容易判断。

推测参照的边界

缺可靠头框时可根据肩宽、躯干和鼻眼点估计头部；帽子和发型容易超出估计。下肢推测需要可靠肩胯与接近直立的躯干，明显坐姿、蹲姿和透视不应依赖同一估计。遮挡的手不自动推算为真实观测。

最低留白、外补与尺寸

进阶#

“视觉平衡 / 留白”中的上、下、左、右是最低留白要求。点击单位按钮在 % 与 px 之间切换；切换单位不会自动换算输入的数字。

设置计算基准例子
上 / 下 %成片高度高度 1200，3% = 36px
左 / 右 %成片宽度宽度 900，2% = 18px
px该输出项的像素尺寸36px 在 1200 高中是 3%，在 2400 高中是 1.5%
0不要求这一侧的最低留白仍可能因比例或其他规则产生空白

顶部从头部参考顶端计算；其余方向按实际采用的保护范围计算。画布读数给出当前采用的上下留白像素；模型参照、比例和偏好都会影响最终值。

试一下：留白换算
仅帮助理解单位，不会修改工作台参数。

外补是面积占比

总外补占比 = 成片中原图外面积 ÷ 成片面积。设置 25 表示 25%，不是向每边扩 25%。额外外补与总上限共同约束偏好搜索；例如最低方案需 10%，再允许额外 15 个百分点，偏好预算最多到 25%。

当前生产输出策略：外补额度超限时保留候选并标为建议复核，尽可能继续输出；“允许虚拟外补”关闭也不是所有兜底分支的绝对禁扩开关。无效坐标、无解或尺寸硬上限仍可能阻止对应结果。

视觉平衡怎样影响构图

进阶#

打开“按躯干角度启用构图偏好”后，按躯干相对画面竖直方向的倾角选择偏好，多人时使用最大倾角。它调整构图焦点和留白，不会旋转照片。

情况默认触发处理方式
直立小于 15°优先安排头肩焦点
对角线15° 起沿躯干倾斜方向安排焦点，并使用下移偏好
横卧60° 起使用横卧上留白偏好

“对角线下移”按原图宽高百分比计算，会影响横向和纵向位置。“横卧上留白偏好”与顶部最低百分比留白取较大值；顶部单位为 px 时不叠加这项百分比偏好。关闭视觉平衡后仍会保留最低留白。

为什么改了参数却看不出变化

偏好需要让位于最低必保、比例、手部、避让与外补预算。参照不足或预算紧张时，系统可能退回更紧凑的结果。建议先临时关闭避让、减小留白，观察偏好单独的影响，再逐项恢复。

“腰胯之间”等短景别采用更紧凑的定位方式，不能把长景别上的变化直接类推。不同姿势应先用代表性照片做小样，而不是只看虚拟骨架。

避让 Logo、文案等区域

进阶#

避让区域的位置相对最终成片。每个区域可独立启用、命名、选择对象和强度。默认预设包含左上 Logo，以及默认关闭的左下文案区域；可按实际版式调整。

字段含义
X / Y区域左上角在成片中的百分比位置
W / H区域宽度、高度占成片的百分比
头部轮廓避开头部参考范围
粗略骨骼避开关节与骨段缓冲范围
身体轮廓避开识别到的人体轮廓；缺少有效轮廓会提示并可能回退骨骼参考

直接在画布调整

点区域卡片上的铅笔图标激活编辑，拖内部移动、拖四角缩放；数字会跟随更新。再次点铅笔或按 Esc 退出。激活编辑后仍可按空格拖动画布，不会把区域一起移动。

强度目标重叠可用动作
严格尽量达到 0%允许移动和额度内扩画幅；达不到时保留最佳候选并提示
适中≤30%允许移动和额度内扩画幅
宽松≤80%单独使用时仅约 3% 位置微调，不为它单独扩大画幅

重叠比例的分母是避让区域面积。例如一块 100×100 的文案区域，被身体轮廓占了 2000 像素面积，重叠是 20%；不是“整个人有 20% 压住文案”。自由模式的多个区域按严格、适中、宽松比较；仅横移和仅纵移模式按卡片从上到下处理，冲突时上方优先。

不同强度偶尔得到相同结果是可能的：当前候选已经同时达标，或其他约束使可用空间很小。查看实际重叠比例和警示，比仅看框是否移动更可靠。

人工复核与确认

新手 / 进阶#
  1. 进入复核。

    点“人工复核”，或从批量结果点“复核此图”。

  2. 选择要调整的内容。

    裁切框、最低必保矩形，或所选人物的头部参考框。

  3. 调整。

    拖内部移动，拖四角缩放，空白处框选。裁切框保持当前比例；空格拖动只移动视图。

  4. 确认。

    检查保留范围后点最右侧“确认复核”，返回裁切画幅。

“清除本比例修正”移除当前比例的手工修正；“按原图扩画幅”保留原图全部像素，只为适应比例补外部空间，不保证人体景别、Logo 或留白已经校验。

确认保存到哪里

复核记录属于当前图片 + 当前比例。同一图片、同一比例的多个输出项会共用这份修正，即使尺寸不同。它不包含在规则或输出组合 JSON 中。

绿色“复核已确认”表示该图片、该比例有人工确认记录。修改人工框会取消确认；普通规则变化不保证全部自动清除既有确认，改变配置后仍应主动复查。刷新或清空图片会丢失本页修正。

输出组合与多规格联动

新手 / 进阶#

右侧“批量输出管理”负责最终多规格。一个组合可以包含 1–12 个输出项；每项有独立名称、启用状态、比例、净宽高、出血、编码和规则快照。

推荐操作顺序

  1. 先把一个规格调好，给输出项起容易区分的名称，如“主图 3:4”。
  2. 添加其他规格，分别设比例和净尺寸。
  3. 点击某张卡片或“载入左侧编辑”，使它与左侧联动。
  4. 调完该项后，可解除联动，再检查其他项。
  5. 最后“新建保存”或“覆盖保存”组合。
操作结果
联动中左侧参数、画布顶部尺寸同步到所选卡片
解除联动左侧变为独立试算，已保存到卡片的规则保留
更新此项规则把当前左侧规则应用到此项；该项的规格仍按自身设置确定
勾选启用参与批量预览、识别与导出
移除输出项从当前编辑组合删除卡片；磁盘原图不受影响
保存组合保存全部项及全局命名、格式、外扩与 AI 设置

普通尺寸修改保持所选比例，改变一边会联动另一边。宽、高为不含出血的净尺寸；出血在四边分别增加。例如净 900×1200、出血 20px，最终为 940×1240。

单图下载与批量导出

入口输出什么需要注意
画布下载 → 当前画幅 PNG当前裁切或全图显示对应的图片范围，PNG不包含骨骼等叠加参考和查看缩放
画布下载 → 外扩底图 PNG当前所需合并范围的原尺寸底图按纯色 / AI 设置填充；有需要时可触发生成

ZIP 或指定文件夹

长按 / 右键“导出结果”，或按向下键，切换压缩包与指定文件夹。不支持目录写入的浏览器会保留 ZIP。目录模式需要主动授权，写入一个新子目录；不会移动原图。

格式与质量

PNG 无损，质量数值不生效；JPEG 与 WebP 的质量为 1–100。JPEG 不支持透明，空白区域填白。每项格式和质量可分别覆盖全局值，未指定的字段继续继承。

结果清单与取消

批量包中包含 manifest.json，记录文件名、裁切范围、尺寸、警示、人工修正、跳过项和可用的 AI 回执。取消会尽量在处理边界停止；已写入目录的文件保留，已运行的 GPU 任务不保证立即停止。

外扩原图始终是单独的无损 PNG，合并成功输出规格的外扩范围，保留原图像素尺度，不替代各规格成片。本次 ZIP 打包有约 128MB 的应用限制，图片过多时分批输出。

文件名、分隔符与目录

新手 / 进阶#

在“全局导出设置”编辑文件命名。原名、规格、比例、宽高、后缀以及 _、\ 按钮会插入光标位置；有选中文字时替换选区。“规格”对应输出项名称，如“主图”，不是自动插入组合名称。

写法内容
{source}原文件名，不含扩展名
{item}输出项名称
{ratio}净比例，冒号变为短横线，例如 3-4
{width} / {height}含出血的实际导出宽高
{trim_width} / {trim_height}不含出血的净宽高
{ext}实际格式后缀 png / jpg / webp
{index}导入图片序号，从 1 开始；同一图不同规格序号相同
\ 或 /在 ZIP / 指定文件夹中建立子目录
命名格式
{source.split("-",1)}\{item}\{source}_{ratio}.{ext}

这会把文件放入首段编号与输出项名称对应的文件夹；下方示例可直接试算最终路径。

拆分原文件名

固定语法是 {source.split("分隔符",段号)}，支持短横线、下划线和空格，段号从 1 开始。它不是任意 JavaScript，不能使用下标、正则、函数链或自定义表达式。空格拆分会合并连续空白；短横线 / 下划线的空段会保留位置。

例如 SKU123-蓝色-01.jpg 的第 1 段是 SKU123，第 2 段是蓝色。缺少指定字段或该字段为空时，相关项会报错并跳过，不会猜一个值填进去。

试一下：最终路径与文件名

使用工作台同一命名解析器。演示按宽 900、出血 0、序号 1 计算，结果不会写入工作台。

重名、后缀与不合法字符

后缀与最终编码格式匹配。批量重名会追加 _2、_3。非法路径字符被清理，Windows 保留名自动处理；目录不能使用空段、. 或 ..。命名总长度上限为 250 字符。

ComfyUI 启动、直连与局域网

新手 / 开发#

顶部 ComfyUI 状态只说明当前连接路径能否读到服务。工程后台连接成功，不等于另一来源的 HTML 浏览器直连也成功。点模型状态进入“浏览器运行设置”，填写地址并点“测试连接”。

方式是否需要网页 CORS怎么选择
工程默认后台连接通常不需要浏览器跨域许可本地版的默认方式
HTML 与 ComfyUI 同源不需要额外 CORSHTML 部署到相同协议、主机和端口内
其他端口或独立 HTML 直连需要 ComfyUI 允许对应来源使用下方兼容启动 BAT，或配置明确来源

兼容启动 BAT

先结束旧 ComfyUI。把下方代码保存为 .bat，放在便携版根目录，与 python_embeded、ComfyUI 文件夹同级，再双击启动。

BAT · 本机与可信局域网兼容
@echo off
cd /d "%~dp0"
.\python_embeded\python.exe -s ComfyUI\main.py --windows-standalone-build --listen "0.0.0.0,::" --port 8188 --enable-cors-header "*"
pause

已有 Start_ComfyUI_Compatible.bat 时可直接使用，不必再新建。仅本机使用可选择 Start_ComfyUI_Local.bat，或把上面的监听参数改成 --listen 127.0.0.1。

兼容模式监听所有网卡，并允许所有网页来源；它不提供身份验证。仅在可信网络使用，不要把 8188 端口转发到公网。浏览器仍可能要求本地网络权限，或阻止 HTTPS 网页访问 HTTP 服务。

地址与错误怎么判断

  • 本机通常填 http://127.0.0.1:8188。
  • 其他设备填运行 ComfyUI 电脑的局域网 IP；不能填那台设备自己的 localhost，也不能把 0.0.0.0 当作访问地址。
  • localhost、127.0.0.1、不同端口都是不同网页来源。改启动参数后必须重启服务。
  • 日志 non matching host and origin ... 403 是来源限制，不是识别模型没有缓存。
  • Prompt executed 只代表生成图执行完成；浏览器仍需能读取历史和下载结果。
  • 端口被占用时先检查旧进程，不要反复启动多个服务，也不要随意结束其他任务。

工作流还需要对应节点及模型。能读到队列不等于所有节点和权重都齐全；缺节点 / 缺模型时按明确报错修复依赖。运行设置内也提供同一份启动说明。

常见任务怎么设置

进阶#
电商照片，一批输出主图与方图

  2. 分别建立主图 3:4 和方图 1:1，给每项独立尺寸与规则。

保留可靠头肩和胯部参照，开启视觉平衡。先用默认 15° / 60°，顶部单位设 % 后再试横卧上留白偏好。观察头肩是否完整，若预算不足，应先调整景别或外补需求，避免只堆高留白数字。

同一图生成一次背景，服务多个比例

在叠加范围里勾选需要的比例，预览合并范围，再执行 AI。设置好最终输出项。批量导出时系统按原图位置判断范围是否覆盖；覆盖且超分 / 羽化一致才复用，否则自动重新生成。

只想下载眼前这一张，不处理整个队列

用画布右上角下载菜单。选择当前画幅 PNG，或当前图片全部规格 ZIP。右侧“导出结果”面向整个导入队列，不会因为你只看着一张图就变成单图下载。

颜色预览和导出不一样预览背景与导出填充是独立设置在全局导出设置里选择纯色 / AI 及颜色
文件名缺字段报错source.split 的段号、分隔符与空段先用 {source}，或统一原文件名结构
结果很多但没有下载点的是批量识别还是导出批量识别不下载，使用导出入口
模板换地址就不见了站点 / 浏览器不同回原地址导出 JSON，再到新地址导入
放大后人物跑出视野查看缩放与平移点左下角恢复默认，不必修改裁切规则
保存组合后照片和复核没恢复JSON 只存设置重新导图，识别与复核记录不在组合 JSON 中

开发：模块与统一定义

开发#

开发源代码保持模块化，单文件只是构建产物。下面是蓝调工作台当前实际模块；不要直接修改生成的 browser/shared/ 或打包后的大 HTML。

坐标与单位

  • 照片几何使用原图像素坐标，左上角原点，X 向右、Y 向下。
  • 裁切框与人工范围是 {left, top, right, bottom}；后台提交扩图 box 为四元素数组。
  • 避让区域的 box 使用成片归一化 0–1 坐标，UI 以百分比显示。
  • 规则输出尺寸是净尺寸；编码尺寸另包含出血。
  • 画布缩放 / 平移只进入显示变换，鼠标坐标经同一逆变换回原图；不把显示缩放写入裁切规则。

同一引擎下比较一致性

比较时固定图片、识别引擎与模式、规则、输出规格、人工修正和代码版本。相同浏览器模型使用 1024 方形补边输入，异常重建可用 768 输入；回执中应保留模型标识、哈希、警示与恢复标记。跨 Holistic 和 Pose Landmarker 的结果差异应单独归因。

本地接口

方法与路径用途 / 主要参数
POST /api/analyzeimage：图片data URL；name；holistic_mode 等，返回识别参数
POST /api/cropimage、box：[left,top,right,bottom]、fill 等；返回图片与画布信息
GET /api/status当前本地后台访问 ComfyUI 的状态
GET /api/agent/v1/manual-templates规则版本列表，返回 templates
POST /api/agent/v1/manual-templatesrule；可选 parent_id，返回 template 保存记录
POST /api/agent/v1/manual-templates/deleteid，删除所选规则版本
GET /api/agent/v1/output-templates输出组合版本列表
POST /api/agent/v1/output-templatestemplate；可选 parent_id
POST /api/agent/v1/output-templates/deleteid，删除对应组合版本族
POST /api/outpaint/jobsimage、box、upscale、feather_px、origin、context
GET /api/outpaint/jobs/{id}轮询 queued / running / completed / failed 等状态
POST /api/outpaint/jobs/{id}/cancel申请取消本任务；不全局打断其他 GPU 任务
JavaScript · 只读列出本地组合
const response = await fetch('/api/agent/v1/output-templates');
if (!response.ok) throw new Error(`HTTP ${response.status}`);
const { templates } = await response.json();
console.log(templates.map(entry => ({
  id: entry.id, name: entry.template.name, version: entry.version
})));

单 HTML 没有自带这些 HTTP 后台服务。共享界面的 API 调用由 BrowserRuntime 适配：模板进 IndexedDB、识别进 Worker、扩图进浏览器 ComfyUI 连接器。不要把纯 HTML 当成一个能接外部 HTTP 请求的 Python 服务。

接口表是当前工作台涉及的路径摘要，不代替完整服务协议。后续 Agent / 执行引擎应复用同一规则定义和验证器，不能只参考界面文字重新实现一个不同的裁切算法。

开发：构建、验证与后续范围

开发#

构建单 HTML

在项目根目录执行：

Shell
python browser/build_single.py

它先构建静态工作台和共享文件，再生成 browser/Hong_AI_浏览器工作台.html。运行库与页面代码内嵌，模型权重外部下载；shared-core-manifest.json 用于核对共享源文件哈希。

本地后台与静态服务

PowerShell
.\start_tool.ps1
# 静态浏览器版，在另一终端运行：
node browser/serve.mjs

本地后台应使用项目 .venv。启动脚本包含 MediaPipe Solutions 检查。浏览器静态服务只提供文件，不提供识别或模板 API；切勿用服务名称掩盖实际运行环境。

最小回归检查

Shell
node browser/verify-runtime-state.cjs
node browser/verify-navigation.cjs

还应按改动核对：六种比例、两种留白单位、三档避让、单人 / 多人、无可靠参照、人工修正、单图与批量导出、命名缺字段、ComfyUI 失败路径。图像导出要读取实际尺寸和 manifest，不能只看“成功”提示。

哪些还属于后续规划

独立持久化大批量 Python 执行引擎、表格字段驱动命名、多种远程来源自动装载和 Agent 自主整理，是统一逻辑规划中的后续方向。本指南不将它们当作当前浏览器工作台已提供的完整功能。

新增功能先修改源模块，同步本地与 HTML，保留固定样本验证。不要给不同端的同名参数赋予不同含义。已有的服务、模板与模型变更应保留迁移与回退记录。

正式交付前

  • 用代表性照片确认景别、头发、手和服装边缘。
  • 确认最终导出尺寸，而不只看画布显示数字。
  • 检查 Logo / 文案的真实重叠与 AI 新增细节。
  • 筛选建议复核，重要图片主动确认。
  • 检查最终文件名、目录与扩展名。
  • 保存输出组合 JSON，保留原图与结果清单。
