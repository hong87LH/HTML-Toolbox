使用指南

切片配置、画布操作与导出流程的快捷参考。

常用快捷键

  • Space按住拖动移动预览画布
  • Shift拖动切片吸附相邻边缘
  • Shift + 点击追加选择多个切片，可整体移动或复制
  • Alt + 拖动松开鼠标复制并放置切片
  • Alt + Shift复制拖动时吸附相邻边缘
  • Alt + 缩放调整大小时吸附相邻边缘或顶点
  • Shift D / Ctrl D复制当前选中切片
  • Ctrl Z撤销最近一次画布切片操作
  • Ctrl Alt Z恢复刚刚撤销的画布操作
  • Alt ↑↓调整当前切片顺序

画布与切片

  • 拖入参考图，自动读取原图宽高。
  • 拖动切片右下角的手柄可调整尺寸。
  • 双击已选中切片可直接输入实际像素宽高。
  • 开启标尺后，坐标按 5px 网格吸附。
  • “适宽”和“全图”是缩放快捷状态，可继续调整缩放。

常见设置参数

  • X1 / Y1 / X2 / Y2：切片左上、右下坐标；支持输入 600+200、20*3 后回车计算。
  • 命名模式与变量：“前缀 + 序号”按最终导出顺序连续编号；“固定名称”可填写文件名或相对路径。支持 {ocr}（完整 OCR）、{ocr_before}（第一个“-”之前）、{ocr_after}（第一个“-”之后的全部内容）、{filename}（原文件名）、{index}（序号）、{width} / {height}（裁切尺寸）。例如 OCR 为 T12345-蓝色-L 时，{ocr_before} 得到 T12345，{ocr_after} 得到 蓝色-L。没有“-”或分隔符一侧为空时，前后变量均回退为完整 OCR；OCR 失败时自动使用原文件名。变量支持 {ocr}、${ocr}、{{ocr}} 三种写法。未写后缀时会按当前导出格式自动补 .jpg / .png；“顺延编号”沿用全局序号。
  • 顺延起始编号：为“顺延编号”指定第一个导出文件的编号；例如填 4，首个文件从 4 开始，后续按导出顺序递增。
  • 默认白底阈值（0–255，默认 250）：用于判断像素是否接近白色，影响“底边裁切”和“纯白跳过”；数值越高，只有更接近纯白的区域会被当作白底，裁切会更保守。
  • 阈值 / 底边裁切 / 纯白跳过：用于自动识别空白底部并处理无内容的切片。
  • 固定名称相对路径：填写 ocr/06 或 /ocr/06.jpg 会输出到 OCR 子文件夹；如果右侧“输出子文件夹”填写 子文件夹，最终路径会组合为 子文件夹/ocr/06.jpg。
  • 按 OCR 建立一级文件夹：默认开启，输出结构为 OCR结果/输出子文件夹/文件名；关闭后不再自动创建 OCR 一级目录，但 {ocr}、{ocr_before}、{ocr_after} 等文件名变量仍可正常使用。该设置会随模板保存，并写入导出 JSON。

主要功能

  • 创建、保存与复用裁切模板；批量粘贴坐标；等分网格切片；按目录或 ZIP 导出；可选 OCR 前缀与本地 OCR 服务。
